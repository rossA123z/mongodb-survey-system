# 05 · 截止时间与关闭问卷

Status: done
Blocked by: 02

## 交付

创建者能设置或调整截止时间、手动关闭问卷；填写者得到明确状态提示，过期或关闭后的提交被拒绝。

## 页面

- 问卷管理页：设置与调整截止时间、关闭问卷。
- 填写页：未发布、已关闭、已截止的明确提示。

## 数据结构

- 截止时间统一存 UTC，网页显示本地时间；截止瞬间视为不可提交。
- 关闭为终态，第一阶段不提供重开。

## 接口

- 设置与调整截止时间。
- 关闭问卷。
- 提交前再次核验问卷是否开放与是否已截止。

## 测试

- 覆盖截止边界、时区、填写中关闭、非创建者操作、草稿不可填写、关闭终态。

## 文档

- 问卷生命周期状态与截止时间存储约定说明。

## 验收条件

- [ ] 创建者可设置与调整截止时间，可手动关闭问卷。
- [ ] 截止时间按 UTC 存储、按本地时间展示，理解一致。
- [ ] 截止瞬间及之后的提交被拒绝。
- [ ] 填写过程中问卷被关闭时，后续提交被拒绝并给出明确提示。
- [ ] 非创建者不能调整截止时间或关闭问卷。
- [ ] 未发布的草稿不能被填写。
- [ ] 关闭后不能重新开放。
