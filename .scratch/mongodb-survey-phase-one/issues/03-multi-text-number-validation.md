# 03 · 多选与填空题及完整校验

Status: done
Blocked by: 02

## 交付

创建者能配置多选的最少、最多或固定选择数，文本的最少与最多字数，数字的范围与是否整数；填写者看到具体错误提示后改正并成功提交。

## 页面

- 草稿编辑页扩展：多选、文本填空、数字填空三种题型及各自的限制配置。
- 填写页扩展：按题型渲染，错误提示定位到具体题目。

## 数据结构

- 题目增加题型与限制字段；固定多选数量与上下限统一为同一约束，矛盾配置在发布校验时被拒绝。

## 接口

- 编辑并保存三种题型及其限制。
- 提交时服务端校验类型、大小与全部限制。

## 测试

- 覆盖边界值、固定数量、无效配置、可选题为空、混合题型答卷。
- 文本按字符计数；数字只接收有限数值，不把布尔值视作数字。

## 文档

- 题型与限制字段说明。

## 验收条件

- [ ] 创建者能配置多选最少、最多或固定选择数。
- [ ] 创建者能配置文本最少与最多字数。
- [ ] 创建者能配置数字范围及整数要求。
- [ ] 矛盾或非法的限制配置在发布校验时被拒绝。
- [ ] 填写者提交越界答案时看到具体错误并改正后成功提交。
- [ ] 可选题留空时不触发限制错误。
- [ ] 单选、多选、文本、数字混合的问卷能完整提交。
