# 02 · 单选问卷发布、填写与提交

Status: done
Blocked by: 01

## 交付

创建者能编辑单选题、发布问卷、取得分发链接；其他账号登录后按必答规则填写并确认提交。默认每账号仅一次提交；匿名开关与重复填写配置在发布前设置，发布后冻结。

## 页面

- 草稿编辑页：添加、编辑、删除、排序单选题，设置选项与必答要求。
- 发布确认页：设置匿名与重复填写策略，发布并展示问卷链接。
- 填写页：打开链接后登录并返回该问卷，逐题作答。
- 提交确认页。

## 数据结构

- 题目与选项使用稳定标识，规则引用标识而非显示序号。
- `responses`：每次成功提交一文档，保存问卷、内部填写者身份、有效答案、提交时间。
- 对禁止重复的问卷，用数据库唯一约束保证同账号并发提交最多成功一次，不能只靠先查后写。

## 接口

- 编辑草稿题目与选项。
- 发布问卷、取得链接。
- 打开链接并登录后返回问卷。
- 提交答卷。

## 测试

- 覆盖有效选项、发布后内容冻结、无效提交、匿名身份不泄露、并发重复提交、多账号提交。

- 发布流程与访问链接说明。

## 验收条件

- [ ] 创建者能添加、编辑、删除、排序单选题并设置必答。
- [ ] 未发布的问卷不能被填写。
- [ ] 发布后可获得可分发链接；发布后题目、选项与跳转规则冻结。
- [ ] 填写者必须登录，登录后能回到该问卷。
- [ ] 答案为无效选项或必答为空时，提交被拒绝并给出定位到题目的提示。
- [ ] 匿名问卷下，创建者看不到填写者身份，系统仍能识别账号以限制重复。
- [ ] 默认每账号每问卷只允许一次成功提交；两个请求并发提交时只成功一次。
- [ ] 多个账号同时提交时，答卷不丢失。
