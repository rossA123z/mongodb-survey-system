# 06 · 问卷与题目统计

Status: done
Blocked by: 04

## 交付

创建者能查看问卷整体统计和题目级统计：单选各选项人数与有效回答总数、多选各选项次数、全部填空内容、数字平均值。

## 页面

- 统计页：问卷级汇总。
- 题目级统计视图：选择某道题查看其统计。

## 数据结构

- 统计只覆盖成功保存的答卷及其有效答案；被跳过或未填的可选题不计为回答；空文本不参与平均值；数字无回答时平均值为空，不显示为零。
- 路径外答案不参与统计（本项验证 04 的失效答案清理在统计侧的效果）。

## 接口

- 获取问卷级统计。
- 获取题目级统计。

## 测试

- 覆盖零答卷、跳过题、可选空值、多次填写计数、匿名与越权隔离。

## 文档

- 统计口径说明（哪些答案计入，空缺如何处理）。

## 验收条件

- [ ] 创建者能看到单选各选项人数与有效回答总数。
- [ ] 创建者能看到多选各选项选择次数。
- [ ] 创建者能看到全部填空内容与数字平均值。
- [ ] 支持问卷级与题目级两种查看方式。
- [ ] 无答卷时统计为空而不是报错；数字无回答时平均值为空而不是零。
- [ ] 被跳过的题、未填的可选题、空文本按口径不计入。
- [ ] 允许重复填写时，每份答卷分别计数。
- [ ] 匿名问卷的统计不泄露填写者身份；非创建者不能查看统计。
