# 04 · 可配置跳转与返回修改

Status: done
Blocked by: 03

## 交付

创建者能为单选、多选、数字题配置条件跳转并排列规则顺序；填写者按有效路径答题、返回修改已答题并确认提交。路径变化后，新路径不再经过的答案被清除，不提交、不保存。

## 页面

- 草稿编辑页扩展：为题目添加跳转规则，调整规则顺序。
- 填写页扩展：按规则跳转、返回已答题修改。

## 数据结构

- 规则引用题目与选项的稳定标识，只可跳向后面的题目或结束。
- 服务端从第一题重算有效路径，不信任客户端声称的路径。

## 接口

- 保存跳转规则与顺序。
- 提交时按有效路径校验必答与格式。

## 测试

- 覆盖多选任一/全部匹配、数字等于/大于/小于/闭区间、命中优先级、默认下一题、跳转到结束、禁止回跳、失效答案清理。
- 统计排除效果不在本 ticket 验证，由 06 验证。

## 文档

- 跳转规则语义与规则顺序说明。

## 验收条件

- [ ] 创建者能为单选、多选、数字题配置跳转，并调整规则顺序。
- [ ] 同一题多条规则命中时，按从上到下第一条生效。
- [ ] 无规则命中时进入下一题；最后一题之后进入提交确认页。
- [ ] 多选支持包含任一指定选项与包含全部指定选项；数字支持等于、大于、小于与含两端的区间。
- [ ] 被跳过的必答题无需填写。
- [ ] 反向跳转或形成循环的规则在发布校验时被拒绝。
- [ ] 填写者能返回修改已答题；路径改变后不再经过的答案被清除，既不提交也不保存。
- [ ] 跳转到结束只进入提交确认页，不自动提交。
