# ADR 0002：题目/规则内嵌与答卷的部分唯一索引

- 状态：已采纳
- 日期：2026-10-17
- 相关工单：`.scratch/mongodb-survey-phase-one/issues/02-single-choice-publish-submit.md`、
  `.scratch/mongodb-survey-phase-one/issues/04-conditional-jump-and-back-edit.md`

## 背景

规格要求：业务数据全部存于 MongoDB，并解释嵌入与引用的取舍、索引与 MongoDB 适用
理由，不机械复制关系数据库表结构；对禁止重复提交的问卷，要用数据库唯一约束保证
同账号并发提交最多成功一次，不能仅靠先查后写。

## 决策

### 1. 题目、选项、规则内嵌进 `surveys` 文档

`surveys.questions[]` 是有序数组，元素含 `options[]` 与 `rules[]`。问卷作为整体读取
（编辑页一次渲染全部题目）、整体校验（发布时一次校验全部题目与规则）、整体冻结
（发布后不可改）。

### 2. 用稳定标识而非显示下标做引用

题目 `qid`、选项 `oid`、规则 `rid` 在创建时分配，不随排序改变。规则与答卷只引用
这些标识。

### 3. 答卷独立成集合 `responses`，并用部分唯一索引防重复

`responses` 每次成功提交一条文档。禁止重复的答卷带 `once: true`，并在
`(survey_id, respondent)` 上建**部分唯一索引**（`partialFilterExpression: {once: true}`）；
允许重复的答卷不带 `once`，不进入该索引。

## 理由

- **内嵌**匹配“一对一整体访问”的访问模式：单文档读写原子，省去跨表 join 与事务；
  题目/选项/规则没有问卷之外的生命周期，共享性为零。
- **稳定标识**让排序与引用解耦：若用下标，上移/下移会改变历史答卷与规则的含义。
- **部分唯一索引**用数据库约束解决并发，而不是应用层“先查后写”（后者在并发下会
  两次都通过查询）：禁止重复时第二个并发插入必然触发 `DuplicateKeyError`；允许
  重复时不进索引，因此同一账号可提交多份且互不覆盖。一个索引同时表达两种策略。

## 影响与取舍

- 内嵌使单份问卷受 MongoDB 单文档 16MB 上限约束；第一阶段问卷规模远低于此，不作为
  问题。若第二阶段单问卷题量激增，需要重新评估。
- 稳定标识比裸下标实现略复杂，但换来排序安全与可靠的连接键。
- `once` 字段是索引语义的一部分：它既是“是否进入唯一约束”的开关，也是“该答卷是否
  参与重复限制”的记录，读取时需注意其语义。
