# 网页操作验收步骤（可复现）

本文是一套**照着点就能复现**的手工验收步骤，覆盖中文表单、错误提示、规则配置、
登录返回、返回修改、确认提交与统计展示。第三方按本文从头操作即可复现，不需要读代码
或数据库。

## 0. 前置

1. 按 `README.md`（或 `docs/configuration.md`）安装依赖并启动：

   ```bash
   cd survey-system
   .venv/Scripts/python -m uvicorn app.main:app --reload
   ```

2. 确认 MongoDB 已在 `127.0.0.1:27017` 运行；浏览器打开 <http://127.0.0.1:8000/>。
   下文所有相对路径都基于该地址（若换了端口，替换地址即可）。
3. 建议用一个从未用过的用户名（示例用 `zhangsan`）以便从干净状态开始；重复操作时
   换新用户名，避免“用户名已被占用”。

每一步格式为 **操作 → 预期**。

## 1. 注册与登录（中文表单）

1. 浏览器打开 <http://127.0.0.1:8000/>。
   **预期**：未登录，自动跳到登录页 `/login`，页面为中文，含“用户名 / 密码”标签与
   “注册新账号”链接。
2. 点“注册新账号”，进入 `/register`。
   **预期**：中文注册表单，含“用户名”“密码”字段与“注册”按钮。
3. 用户名填 `zhangsan`，密码填 `secret123`，点“注册”。
   **预期**：注册成功，跳回 `/login` 登录页。
4. 在登录页填同样的用户名与密码，点“登录”。
   **预期**：进入“我的问卷”页 `/surveys`，页头显示当前用户名 `zhangsan` 与“退出”。

（错误提示顺带验收：在第 3 步改用已存在的用户名再注册，**预期**页面红字提示
“用户名已被占用”。）

## 2. 新建问卷草稿

1. 在“我的问卷”页点“新建问卷”，进入 `/surveys/new`。
2. 标题留空，直接点“创建草稿”。
   **预期**：页面提示“请填写问卷标题”，不创建。
3. 标题填“数据库课程问卷”，说明填“第一阶段演示问卷”，点“创建草稿”。
   **预期**：回到“我的问卷”，列表出现“数据库课程问卷”，状态显示“草稿”。
4. 点该问卷条目下面的“管理 / 查看”。
   **预期**：进入编辑页 `/surveys/{id}/edit`，显示状态“草稿”与“添加题目”表单。

## 3. 添加四种题型（中文表单 + 限制配置）

在编辑页下方的“添加题目”表单里依次添加四道题（每次选好题型、填题干、按需设置限制，
点“添加题目”）：

1. 题型“单选题”，题干“你平时使用哪种数据库？”，勾选“必答”，三个选项分别填
   “关系型数据库”“文档数据库”“图数据库”（表单默认两行，点“添加选项”追加第三行），
   点“添加题目”。
2. 题型“多选题”，题干“你了解哪些 MongoDB 特性？”，勾选“必答”，选项填
   “副本集”“分片”“聚合管道”（点“添加选项”追加第三行），把“最少选择数”填 `1`，
   点“添加题目”。
3. 题型“数字题”，题干“你每周投入学习多少小时？”，勾选“必答”，“最小值”填 `0`、
   “最大值”填 `168`，勾选“只接受整数”，点“添加题目”。
4. 题型“文本题”，题干“补充说明（选填）”，“最多字数”填 `20`，点“添加题目”。

**预期**：编辑页依次显示第 1~4 题，各题标注题型；第 1、2、3 题标“（必答）”。

## 4. 配置跳转规则（规则配置）

1. 在第 1 题下方找到“跳转规则”表单，作如下设置：
   - “跳转目标”选“第 3 题 你每周投入学习多少小时？”；
   - “触发条件：选中该选项”的下拉里应列出“关系型数据库 / 文档数据库 / 图数据库”
     三个选项，选“关系型数据库”。
2. 点“保存规则”。
   **预期**：回到编辑页，第 1 题规则表单里“跳转目标”仍为第 3 题、“触发条件”仍为
   “关系型数据库”，说明规则已保存。

## 5. 发布问卷

1. 点编辑页底部的“去发布”，进入 `/surveys/{id}/publish`。
2. 勾选“匿名填写”。**不勾**“允许同一账号重复填写”。
3. 点“发布问卷”。
   **预期**：回到编辑页，状态变为“已发布”，页面顶部出现“可分发的填写链接：`/s/{id}`”。

## 6. 登录返回（另一账号）

1. 打开一个**新的隐私/无痕窗口**（确保未登录），访问填写链接 `http://127.0.0.1:8000/s/{id}`。
   **预期**：跳到登录页，地址栏带 `?next=/s/{id}`。
2. 在该窗口注册并登录一个新账号（如 `respondent1`）。
   **预期**：登录成功后**自动回到**填写页 `/s/{id}`，而不是“我的问卷”。

## 7. 错误提示（定位到题目）

1. 在填写页：第 1 题选“文档数据库”；**第 2 题不选任何选项**；第 3 题填 `5`；
   第 4 题留空；点“下一步”。
   **预期**：回到填写页，第 2 题下方红字提示
   “第 2 题“你了解哪些 MongoDB 特性？”为必答题，请至少选择一项”，已填内容保留。
2. 第 2 题选“副本集”；把第 3 题改成 `999`；点“下一步”。
   **预期**：第 3 题下方红字提示“…不能大于 168”。
3. 把第 3 题改回 `5`，第 4 题填“第一阶段”，点“下一步”。
   **预期**：进入“确认提交”页，逐条列出四道题的回答。

## 8. 返回修改与确认提交

1. 在确认页点“返回修改”。
   **预期**：回到填写页，各题**回填**刚才的答案（第 1 题“文档数据库”已选中、
   第 4 题文本框为“第一阶段”）。
2. 点“下一步”回到确认页，点“确认提交”。
   **预期**：进入“提交成功”页，提示答卷已保存。

## 9. 重复提交限制

1. 用同一账号 `respondent1` 再完成一次填写并点“确认提交”。
   **预期**：不能提交，页面提示“你已经提交过这份问卷，不能重复提交”。

## 10. 统计展示

1. 切回创建者 `zhangsan` 的窗口，进入“我的问卷”，点问卷的“管理 / 查看”。
2. 点“查看统计”，进入 `/surveys/{id}/stats`。
   **预期**：
   - 顶部“已收到答卷：1 份”；
   - 第 1 题（单选）列出“关系型数据库：0”“文档数据库：1”“图数据库：0”，并显示
     “有效回答总数：1”；
   - 第 2 题（多选）列出“副本集：1”“分片：0”“聚合管道：0”；
   - 第 3 题（数字）显示“平均值：5”；
   - 第 4 题（文本）列出“第一阶段”。
3. 在某题下点“查看该题统计”。
   **预期**：进入题目级页面 `/surveys/{id}/stats/{qid}`，显示该题的统计与“返回问卷统计”。

## 11. 跳转路径验收（可选，验证“跳过必答”）

1. 用**另一个新账号**（如 `respondent2`）登录，打开 `/s/{id}`。
2. 第 1 题选“关系型数据库”。
   **预期**：按规则跳过第 2 题，页面不再显示第 2 题（前端即时隐藏）。
3. 点“下一步”。
   **预期**：直接进入确认页，**第 2 题虽是必答但无需作答**（它不在有效路径上）。

## 12. 截止与关闭（可选）

1. 创建者在编辑页“截止时间”里选一个**过去**的本地时间，点“保存截止时间”。
2. 打开 `/s/{id}` 或再次提交。
   **预期**：提示“问卷已截止，不再接受答卷”。
3. 创建者点“关闭问卷”，再打开 `/s/{id}`。
   **预期**：提示“问卷已关闭，不再接受答卷”；已关闭问卷不再提供重新开放入口。

## 13. 与自动测试的关系

本手工验收覆盖浏览器交互；接口行为由自动测试覆盖（见 `docs/test-record.md`）。
两者互补：接口测试不能代替浏览器交互验收，浏览器步骤也不替代回归测试。
