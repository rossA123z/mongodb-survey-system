## 发现的问题

### 1. F2：经注册流程丢失原问卷返回地址

复现：全新浏览器会话打开问卷填写链接 → 登录页地址含 next=/s/{id} → 点击“注册新账号” → 注册新账号 → 登录。
预期：回到原问卷填写页。实际：回到 /surveys（我的问卷）。已登录状态有效，手工重新打开问卷链接后可填写。
影响：分享链接的新用户无法在注册登录后自动继续填写。建议使 next 在注册页、注册成功后的登录页及表单之间完整保留，同时继续限制为安全站内地址。此为基于交互的修复建议，未修改实现。

### 2. 附加 X1：已发布问卷管理页不显示题干

复现：创建四题问卷并发布 → 返回 /surveys/{id}/edit。
实际：四题都只显示“第 N 题（题型）（必答）”及选项，没有题干；数字和文本题没有选项，创建者更难核对内容。
填写页和统计页仍显示原题干，所以这是管理页的呈现缺失，未发现题干数据丢失。建议冻结编辑后保留只读题干。

### 3. K3：验收文档顺序与必答规则矛盾

K2 选“关系型数据库”后跳过第 2 题，但第 3 题仍是有效路径上的必答题。K3 要求不填第 3 题就进入确认页，而 K4 才要求填 5；实际 K3 被正确提示“第 3 题…为必答题，请填写数字”。
建议将“第 3 题填 5”移到 K3 点击下一步之前；K4 再确认提交。该补充动作后 K4 提交成功，确认页不含跳过的第 2 题。
